# NeyroTokBot

Telegram-бот для генерации видео **SD 2** и **SD 2 Fast** через сайт https://okroshka-su6j.onrender.com/.

Бот открывает сайт в браузере (headless Chromium) и сам заполняет форму: модель, промпт, референсы, длительность и формат. Потом нажимает «Сгенерировать видео», дожидается ролика и присылает его в чат. Токены API сайта не нужны.

## Как пользоваться

```
/sd2fast кот в скафандре идёт по Луне
/sd2 10s 9:16 неоновый Токио под дождём
```

1. Команда открывает **панель**. В ней можно переключить модель, выбрать длительность (4–15 сек, кнопки ➖/➕ и пресеты) и формат (16:9, 9:16, 1:1).
2. Референсы просто присылайте в чат: фото (до 8), видео (до 3), аудио или голосовые (до 3). Можно альбомом. Можно отправить альбом с подписью `/sd2 промпт`, и всё подхватится сразу.
3. Новый текст заменяет промпт.
4. **🚀 Сгенерировать**: панель превращается в статус (очередь, загрузка, генерация, секунды). Есть кнопка «Отменить».
5. Бот присылает видео с подписью и кнопкой «Скачать». Если генерация не удалась, появятся кнопки «🔁 Повторить» и «✏️ Изменить».

Другие команды: `/queue` показывает очередь, `/cancel` закрывает черновик, `/help` выводит справку.

### В группе
Бота можно добавить в группу. Команды работают как обычно (`/sd2` или `/sd2@имя_бота`). Текст и файлы для панели отправляйте **ответом (reply) на панель**, чтобы бот не подхватывал чужие сообщения. Нажимать кнопки может только тот, кто открыл панель.

### В канале
1. Канал → Управление каналом → Администраторы → Добавить администратора → найдите бота.
2. Дайте права: **публикация сообщений**, **редактирование**, **удаление**.
3. Опубликуйте в канале пост `/sd2fast промпт` (можно с фото). Панелью управляют только админы канала, подписчики нажать кнопки не могут.
4. После генерации в канале остаётся только пост с видео. Командный пост, панель и статус бот удаляет (отключается через `CHANNEL_CLEANUP=0`).

### Публичный доступ
По умолчанию бот открыт для всех. Защита от перегрузки:
- `DAILY_LIMIT`: сколько видео в сутки на человека;
- `MAX_ACTIVE_PER_USER`: не больше N заданий в очереди от одного человека;
- `MAX_PARALLEL`: сколько видео генерируется одновременно, остальные ждут в очереди с номером;
- `ADMIN_IDS`: на вас лимиты не действуют;
- `ALLOWED_CHATS`: если заполнить, бот будет работать только в указанных чатах.

Лимиты хранятся в памяти и сбрасываются при перезапуске бота.

## Деплой на Render (бесплатно)

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot`: имя `NeyroTokBot`, username `NeyroTokBot` (если занят, подойдёт `NeyroTok_bot` и т.п.). Скопируйте токен. Имя и описание бот потом выставит себе сам при запуске.
2. Залейте эту папку в новый репозиторий на GitHub (можно приватный).
3. На [render.com](https://render.com): **New → Web Service**, подключите репозиторий. Runtime: **Docker**, Instance type: **Free**.
   Если хотите взять настройки из `render.yaml`: **New → Blueprint**.
4. В **Environment** добавьте `BOT_TOKEN`, свой `ADMIN_IDS` и при желании `DAILY_LIMIT`.
5. Нажмите Deploy. Render сам передаёт боту адрес (`RENDER_EXTERNAL_URL`), и бот включает вебхук.
6. **Чтобы бот не засыпал**: бесплатный сервис Render засыпает после 15 минут без запросов. Зарегистрируйтесь на [cron-job.org](https://cron-job.org) (бесплатно) и настройте запрос раз в 10 минут на `https://ВАШ-СЕРВИС.onrender.com/health`.

Проверка: откройте `https://ВАШ-СЕРВИС.onrender.com/health`. Должен вернуться ответ `{"ok": true, ...}`.

### Если Render падает по памяти
На бесплатном тарифе 512 МБ. Chromium в него помещается при `MAX_PARALLEL=1`. Если в логах видно `Out of memory` или бот перезапускается, поставьте `ENGINE=direct`. В этом режиме бот обходится без браузера и отправляет на сайт ровно те же запросы, что и кнопка «Сгенерировать». Памяти он требует около 60 МБ.

## Запуск на своём ПК / VPS

```bash
cp .env.example .env      # впишите BOT_TOKEN
pip install -r requirements.txt
playwright install --with-deps chromium
python bot.py
```
Если `WEBHOOK_URL` не задан, бот работает через long polling, и внешний адрес ему не нужен.

## Ограничения
- Telegram отдаёт ботам файлы **до 20 МБ**. Более тяжёлые референсы придётся сжать.
- Отправить видео бот может **до 50 МБ**. Если ролик больше, бот пришлёт ссылку на скачивание.
- Сайт-провайдер тоже стоит на бесплатном Render. Если он спал, первая генерация начнётся на 30–60 секунд позже: бот подождёт и попробует снова.
- Если на сайте поменяют вёрстку (id полей `#prompt`, `#dur`, `#ratio`, `#go` и т.д.), режим `browser` нужно будет поправить в `engine.py`.
